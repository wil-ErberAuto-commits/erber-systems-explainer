Buttons

There is one primary button per view; secondary is for supporting actions and ghost for everything else. The standard height is 40, and 32 is for compact spots inside cards and rows.

Segmented tabs and search

The segmented control is the only tab style. It's used for switching views on a page and for picking a mode inside a panel. Search is a standard input with a leading icon and an optional key hint.

Chips and status

A status chip is a dot plus a short label, and its colour comes only from the status tokens. A count chip is muted, never coloured.

Cards

A compact card has an icon tile, title, subtitle, one line of metadata and one action. Use cards for a set of peer items, never as page structure, and never put a card inside another.
